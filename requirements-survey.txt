# this repo gives you still installs everything. If you want the lighter set -

# requirements-nt.txt instead and save about 225 MB.
-r requirements-nt.txt

# Needed by:
#   survey/solve_layout.py   bundle-adjusts recorded corners into a layout
#
# scipy is 90 MB and OpenCV is 135 MB, and solve_layout.py is the only thing in
# the repo that imports either. field_viewer.py will USE cv2 if it is present,
# to compute field of view from the real distortion model instead of a pinhole
# approximation - worth having, since pinhole reads 60.1 deg on an OV9281 where
# the truth is 69.4 and draws blind spots that are not there - but it falls
# back cleanly when cv2 is absent.
scipy
opencv-python-headless
